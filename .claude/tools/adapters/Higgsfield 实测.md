# Higgsfield 实测与坑

> 只记官方文档没有、再踩一遍要花钱的事，每条带日期。用哪个模型、命令怎么写、参数怎么传，看官方的 higgsfield-* 技能和 `higgsfield model get`，这里不重复。

- 登录后必须 `higgsfield workspace list` → `higgsfield workspace set <id>`，否则所有调用报 No workspace selected（2026-10-15）。
- `account status --json` 里有账户邮箱：只取 credits 和 subscription_plan_type，不打印原文（适配的 check 已这样做）。`higgsfield auth token` 会把令牌明文打出来，hook 拦。
- 价格现查：`higgsfield generate cost …`（不花钱，参数同 create；本地素材估价时也会上传）。2026-10-15 的量级：Seedance 2.5 每秒 480p 3 / 720p 7 / 1080p 16 积分；GPT Image 2.5 high 2k 2.75；Seedream 5.0 Pro 2k 2.5；Soul 2.0 0.12。
- 草稿：`--draft true` 按 480p 价出；升级必须显式写 `--draft false --draft_job_id <草稿任务号>`，不写会被命令行校验拦下（Unsupported validation rules）；升级按目标分辨率全价收（1080p 5 秒 80），构图、运镜、光和草稿几乎一样，只是变清楚（2026-10-16）。
- 任务状态 `ip_detected`：被知识产权检测拦下，没有结果，积分自动退回；同一品牌名别的任务却过了，触发条件不明（2026-10-16）。虚构品牌名先查一下别撞真实品牌（NOCTA 是 Nike 的子品牌）。
- 估价和实扣：出图一致（2026-10-16，4 张 10.87）；Seed Audio 估 0.4 实扣 1.2（2026-10-15）。花完拿 `account transactions --size N` 对账。
- 真人照片直接挂 `--image-references` 没被拦，出来认得出是本人；官网真车图当产品参考、提示词不写品牌名也没被拦（2026-10-16）。
- `@image1、@image2…` 按挂图顺序指代能认（2026-10-16，三张图各自对上）。
- 参考图的背景会被整张搬进画面：提示词写"和 @imageN 完全一样"时，影棚底、灯、机位一起进来（2026-10-16）。
- 从一张静态首帧起步的段，画面普遍只剩镜头缓推（2026-10-16：19 条单镜头运动量中位数 0.9～8.5，红牛参考 12.2，pick.py takes 量的）。
- 自带现场声约 -29 LUFS，偏小（2026-10-15）。
- 视频参考（`--video-references`）、首尾帧、video_edit / video_extension、Sonilo 配乐、Soul 训脸：有通道，没实测。第一次用先出一条。
- 官方 generate 技能写着"别主动报价"：和这里"花钱前先估"冲突，以这里为准。
- 配乐描述可能被当歌词唱出来：要纯器乐写清楚，出完听写一遍（4.0 的经验，Higgsfield 上未复核）。
- Soul 2.0（text2image_soul_v2）挂一张人像参考：两张都照搬了参考图的构图（灰底胸像、黑 T 恤），提示词里的服装和场景全没听，脸也换成了别人。要换装、保本人别用它（2026-10-17，2 张 0.24）。
- Seedream 5.0 Pro 挂三张本人照片（近景、全身正面、全身侧面）换装进场景：脸对得上，皮肤有毛孔、基本不油，服装和场景都听了（2026-10-17，一张 2.5）。
- Soul Location 出无人赛道夜景（16:9，一张 0.12）：质感真，看台观众是远处的小人，能用；两张里一张偏糊（2026-10-17）。
- GPT Image 2.5 medium 2k（一张 1.0）出道具：写了 "small aero spoiler" 会长出尖角，要写 "smooth rounded shell, no spoiler, no fins"（2026-10-17）。
- 草稿升级的价按 1080p 每秒 16 收，目标写 720p 也一样，而且出来的就是 1920×1080（2026-10-17：S01 10 秒草稿"升 720p"实扣 160，文件 1080p；直接出 720p 每秒 7）。720p 的片子别走"草稿→升级"（3+16=每秒 19），直接出 720p；草稿只在新做法第一次探路时用。
- 官方渲染效果图（影棚底）直接挂成 Seedance 的产品主参考：车出来一股 CG 味（太干净、没反光、像贴上去的）；镜头构图像某张效果图时，会把那张图的机位、影棚灰地板、黑底整张搬进来。悬浮宣传图（车尾正面 + 白气 + 黑底）最严重，挂了它的三段都照抄（2026-10-17：S08、S11、S14）。做法：先用 GPT Image 2.5 high 挂官方图出"实地拍的真车"关键帧（湿漆面、雨珠、路脏、真反光），核过造型后拿它当主参考或首帧，官方图只在要对结构时挂、写明 design only（2026-10-17，一张 2.75）。
- GPT Image 2.5 high 出实拍感车辆照：造型准（车头棱面、灯带、6 辐白轮面、RDSTR 车牌都对），质感最真；同样提示词 Seedream 5.0 Pro 把车头拉长、辐条数出错（2026-10-17）。
- 戴头盔的人像关键帧：Seedream 第一张脸跑成别人（脸窄、双眼皮）；GPT Image 2.5 high 挂定妆照 + 本人照片 + 头盔、提示词逐条写脸部特征（宽圆脸、小单眼皮、鼻头圆），脸对上、皮肤哑光有毛孔（2026-10-17）。
- Seedance 出的面罩里的人脸容易油亮（S06、S10），首帧给哑光皮肤的关键帧再起步（2026-10-17 待验证）。
- review_seg.py 的听写默认按中文，英文台词会听成乱码；英文用 qa.py stt --lang en（2026-10-17：S06 换英文后字错率 0）。
- 提交时偶发 HTTP 520（上传素材失败），任务没建、不扣费，重跑同一个 jobs 文件就会补交（2026-10-17：S03、S04）。
- account transactions 的 --size 最大 100（2026-10-17，写 120 报 query.size ≤ 100）。
- 产品比例最稳的关键帧做法：只挂一张官方图，提示词写"Edit this photo. Keep the car exactly as it is…change only the scene and the light"，GPT Image 2.5 high 会原样保留车的造型和比例，只换背景、天气和光（2026-10-17：官方俯视图 M02 换成夜间湿赛道，长宽比 2.45 对官方 2.39）。直接让它"按参考画一张俯视图"，车会又短又胖。
- 首帧关键帧里车头的样子会被同图里别的车带偏：轮对轮正面图同时挂了黑色原型赛车，白车也长出窄高气泡座舱；逐条写清车头特征（宽低平楔形、整宽灯带、宽低顶篷、no bubble cockpit）就对了（2026-10-17）。
- Seedance 从哑光皮肤的首帧起步，出来的脸还是会带一点反光；人脸近景在剪辑里别加高光光晕（会放大反光），再压一点高光（2026-10-17）。
- 总装（assemble.py）用 -ss 加 fps=24 截取：入点刚过一帧边界时，首帧会重复一次，两帧闪切只剩一张静帧。剪辑表里把入点对齐到"整帧前 1/4 帧"、时长取整帧就没了（2026-10-17，本项目 剪辑/剪辑表.py 的 v()）。已在 assemble.py 里修掉（2026-10-17）：seek_in() 把视频入点对齐到离它最近的整帧前 1/4 帧，fps 前再加 setpts=PTS-STARTPTS 兜底（源片 30/25fps、或视频流比音频晚 0.02 秒起时，只对齐还会重复），剪辑表不用再自己对齐；v() 对齐过的入点工具再算一遍不变。
- whisper 在纯音乐、音效上会幻听出 "Thanks for watching" "中文字幕志愿者" 之类；判断有没有人声要看 no_speech 概率或音节节奏，不能只看听写有没有字（2026-10-17）。
- Nano Banana Pro（nano_banana_pro，2k 一张 2 积分，最多 14 张参考）挂官方车图 + 场景图出"实拍感车辆参考"：同一提示词下比 GPT Image 2.5 干净（没有那种又脏又油的颗粒感）、反光真，造型对得上官方图；车尾 RDSTR 车牌、四喷口、尾翼也对。提示词别写 grime / mud / road spray，写 clean, freshly washed, few water droplets（2026-10-17）。
- Soul 2.0（text2image_soul_v2）只能挂 1 张参考，挂官方车图出的两张都是别的车（换了车头、换了轮毂），产品图别用它（2026-10-17）。
- Seedance 2.5 参考模式、不用首帧、只挂一套参考包（场景 1 + 车外观 1 + 车尾 1 + 对手车 1）：追逐 9 秒、终点 12 秒都是真运动、车前后一致、像实拍，明显好过"关键帧当首帧"——首帧起步的段普遍只剩缓推，像照片放大，而且人和车会被首帧那张图带偏（2026-10-17：S15、S16）。
- 同一条里让车"空中横滚一圈再落地"：横滚本身能拍，但车翻正、下落那 1～1.5 秒车顶鼓成大泡、车身被拉高（S16 源 6.42–7.92）。加速盖不住：4 倍速像瞬移，2～3 倍速露变形；最后靠插一个反应镜头跳过（2026-10-17）。
- 一次提交 9 秒和 12 秒两条，12 秒那条估价接口返回空（估不出），实扣 84 = 每秒 7（2026-10-17）。
